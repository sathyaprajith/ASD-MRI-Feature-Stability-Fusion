The historical stage1 and stage2 Python files were supplied in the authors'
11 November 2026 research handoff. The repeated copies of stage1 were identical;
one copy is retained. `code/stage1/vendor/v4` is the research reference code from
that same archive. Its upstream permission terms were not supplied. Original
source hashes and file lineage are recorded in `provenance/`.

No upstream copyright notices were removed. There was no LICENSE or CITATION file
in the supplied archive, including its nested ZIPs. `LICENSE` therefore retains
rights; it does not invent MIT, Apache, BSD or other permissions. Check ownership
and any employer/institution or third-party terms before granting an open-source
license. The package can be hosted as a source-available repository without
representing it as open-source.

NumPy, pandas, SciPy, scikit-learn, PyTorch, joblib, Matplotlib and pytest are
external dependencies installed separately. Consult each installed distribution's
license notices. No library binaries or ABIDE participant data are bundled.
